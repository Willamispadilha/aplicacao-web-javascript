# Aplicação Web Interativa com JavaScript

## 📌 Sobre o projeto

Este projeto foi desenvolvido como parte de uma experiência prática acadêmica do curso de **Análise e Desenvolvimento de Sistemas**. O objetivo é transformar uma interface estática em uma aplicação web dinâmica, funcional e interativa.

## 🎯 Objetivo

Desenvolver uma aplicação utilizando JavaScript para praticar manipulação do DOM, eventos, formulários e armazenamento de informações no navegador.

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* DOM
* LocalStorage
* Git e GitHub

## 💡 Funcionalidades

A aplicação será desenvolvida com recursos de interação com o usuário, permitindo:

* Inserir informações por meio de formulários;
* Manipular elementos da página dinamicamente;
* Responder às ações do usuário;
* Armazenar dados utilizando LocalStorage;
* Exibir e atualizar informações sem recarregar a página.

## 📚 Aprendizados

O desenvolvimento deste projeto permite aprimorar conhecimentos em JavaScript e desenvolvimento web, especialmente na manipulação do DOM, utilização de eventos e armazenamento local. Também contribui para desenvolver raciocínio lógico, organização de código e boas práticas de desenvolvimento.
